# CV site builder MVP

This is an app where logged-in user is able to create a simple CV website
by entering desired information and selecting a predefined design. Website 
is locked under custom pin code which is requested upon entry.

### Main functionality:
- User register/login on homepage
- User site control panel:
  - enter data (name, contact info, experience, etc.)
  - select design with live preview
  - set custom pin code
- Generate and download simplified PDF of CV
- User's site is accessible via custom subdomain (mysubdomain.domain.lt)
- Site is hidden until pin code is entered
